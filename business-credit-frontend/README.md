# Кредит под ваши планы

Frontend-прототип кабинета малого и микробизнеса для Альфа Хак 2026. Интерфейс основан на предоставленном примере; состояния заявки согласованы с предоставленной схемой кредитного пути. Это frontend-часть командного решения, а не готовая банковская система.

## Запуск

Без сборки, Node.js и npm. Откройте `dist/index.html` в браузере или запустите статический сервер:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080. Сохранение через localStorage надёжнее при запуске через HTTP. Для Docker требуется установленный Docker с Compose:

```sh
docker compose up --build
```

Откройте http://localhost:8080. Версия Nginx зафиксирована в Dockerfile: 1.27.5-alpine. JS-библиотек нет; lock-файл не требуется. Переменные окружения и ключи API не нужны. Docker-сборка требует получения публичного образа. В этой среде Docker не запускался.

## Реализовано

- Параметры: цель, сумма, срок, комфортный платёж, срочность. Срочность не обещает выдачу.
- Три синтетических бизнес-продукта с проверкой совместимости, аннуитетом, переплатой и полной суммой выплат. ПСК не рассчитывается: демомодель не содержит дополнительных расходов.
- Сортировка, сравнение, подробные условия и персонализированная тематическая лента, меняющаяся вместе с целью.
- Три шага заявки: компания, финансы, обзор и явное согласие на отправку.
- Черновики, список заявок, история переходов, сохранение после перезагрузки в этом браузере.
- Локальные симуляторы реестра, БКИ, скоринга и кредитных правил. Нет запросов в банковские системы.
- Уточнение сведений, повторный запрос при неполном ответе, технический сбой с повтором, одобрение, отказ, контрпредложение с принятием конкретной версии и закрытие клиентом.
- Помощник по правилам: распознаёт оборотные средства, оборудование, вопросы о платеже и заявке. Это не LLM. Можно заменить на открытую модель через backend команды.
- Адаптивные стили для экранов до 800 px, семантические формы, клавиатура, модальные диалоги.

## Архитектура и интеграция

`dist/index.html` — разметка; `dist/styles.css` — оформление; `dist/app.js` — интерфейс и локальная демологика. Для передачи в командный репозиторий нужны эти файлы, Dockerfile, compose.yaml и nginx.conf. Файлы `.openai` относятся только к демонстрационному хостингу.

Все данные находятся в объекте `state`; `persist()` записывает его в localStorage с ключом `business-credit-v1`. Это не серверное хранилище и не авторизация: другой браузер не видит эти заявки, пользователь может изменить их через DevTools. Используйте только синтетические сведения. Файлы не загружаются: сохраняются только имя и размер. Нет подписания, выдачи денег, настоящего скоринга, банковской панели или роли сотрудника.

Серверные endpoints сейчас НЕ реализованы. Предлагаемый контракт для backend — в `docs/openapi.yaml`. При интеграции замените `persist`, `schedule`, `runChecks`, `decide` на вызовы API и опрос состояния. Проверки, скоринг, авторизацию, права, валидацию, идемпотентность, версионирование предложения и долговременное хранение необходимо выполнять на сервере. Демо-переключатель сценариев нужно оставить только в тестовом режиме.

Схема компонентов и состояний — `docs/architecture.md`; модель данных и ограничения — `docs/data-model.md`; сценарии проверки — `docs/test-scenarios.md`. Формула аннуитета: P = S × r / (1 − (1 + r)^−n), r — годовая ставка / 1200; округление только при отображении.

## Быстрая проверка

1. Оставьте 1 500 000 ₽, 24 месяца, платёж 90 000 ₽. Обновите подбор и сравните два продукта.
2. Оборотный кредит → Подробнее → Выбрать → Заполнить тестовым профилем.
3. Закройте окно. Откройте «Мои заявки», продолжите тот же черновик, проверьте сохранённые поля.
4. Продолжите до обзора, отметьте согласие, отправьте. После локальных проверок появится «Одобрено». Деньги не выдаются.
5. Создайте ещё один черновик и на последнем шаге выберите другой демонстрационный сценарий. Все ветки доступны без платных сервисов.
6. Выберите цель «Покупка оборудования», обновите подбор: продукты и лента поменяются.
