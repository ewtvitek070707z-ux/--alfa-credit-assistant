# Тестовые сценарии

Общие данные: оборотные средства, сумма 1 500 000, срок 24, комфортный платёж 90 000. Кнопка «Заполнить тестовым профилем»: ООО «Вектор» (демо), ИНН 0000000000, возраст 24 мес., выручка 1 200 000, расходы 700 000, кредиты 30 000 ₽/мес.

| Проверка | Действия | Ожидаемый результат |
|---|---|---|
| Подбор | Изменить сумму, срок; обновить | Платёж и общая сумма меняются |
| Нет продукта | Недвижимость, 100 тыс., 6 мес. | Объяснение несовпадения; нет отказа по заявке |
| Неполные данные | Очистить сумму / обязательное поле формы | Браузер указывает поле; введённый черновик сохраняется |
| Сравнение | Добавить/удалить продукты | Таблица и счётчик меняются; несовместимый продукт нельзя выбрать |
| Черновик | Заполнить шаг 1, закрыть, перезагрузить | Та же заявка в списке; поля сохранены |
| Одобрение | Профиль по умолчанию, согласие, отправка | SUBMITTED → ENRICHING → SCORING → APPROVED |
| Уточнение | Сценарий «Запрос дополнительных сведений» | NEED_MORE_INFO, понятный вопрос |
| Неполный ответ | Пояснение «Мало», отправить | Ошибка с минимумом 20 символов; статус сохраняется |
| Полный ответ | Подробное пояснение источника средств | Повторные проверки → результат |
| Сбой | Сценарий сбоя, затем повтор | CHECKS_UNAVAILABLE → ENRICHING → результат, тот же id |
| Контрпредложение | Соответствующий сценарий, принять | Меньшая сумма; принятие конкретной версии → APPROVED |
| Отклонение | Контрпредложение, отклонить | CLOSED_BY_CLIENT |
| Отказ | Сценарий просрочки | REJECTED, объяснение, новый подбор |
| Правила | Возраст 3 мес. или расходы выше выручки | Отказ независимо от обычного сценария одобрения |
| Лента | Поменять цель на оборудование, обновить | Тематические карточки изменились; открываются |
| Помощник | Ввести «Нужно оборудование» | Объяснение и обновление цели; без обещания одобрения |
| Возобновление | Перезагрузить во время проверки | Возобновление того же обращения |
| Двойная отправка | Повторить нажатие | Одна заявка, проверка текущего статуса |

Браузерная проверка 23.10.2026: основной путь, неполное и полное уточнение, технический сбой с повтором, принятие контрпредложения и отказ пройдены. Docker в среде разработки не запускался. Адаптивность предусмотрена CSS, отдельная мобильная браузерная проверка не выполнялась.
